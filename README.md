# Bittle-servo crane

A two-joint arm with a gripper, driven by three Petoi Bittle servos. Both arm servos sit on the base; a parallelogram
linkage carries the elbow drive up the arm, so only the gripper servo rides on the arm.

Open `index.html` in a browser for the interactive side view, torque check, dimensions, parts and control notes.

Status: design only, not built or tested. The servo stall torque (3 kg·cm) is from a reseller listing and unconfirmed.
